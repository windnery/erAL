# M4 皮肤系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现皮肤数据、购买（经明石）、换装指令、前端头像/立绘切换与换装专属口上。

**Architecture:** 新增 `SkinManager` 读取 `data/skins.json`；`ShipGirl` 新增运行时字段 `skin`（登记进 M0 存档协议）；`change_skin` 指令切换当前皮肤；购买复用 M2 的 `buy` 指令（明石商品表填充 `type: skin` 条目，M2 已实现 `player.skins[npc_id]` 写入逻辑）。前端头像排与立绘全屏层的图片路径按 `npc.skin` 选择资源（`assets/skins/{id}/{skin_id}.webp`，缺失回退默认）。口上条件新增 `skin`（M1 预留点）。

**Tech Stack:** Python 3.11+ 标准库（unittest），前端原生 JS。

```python
import json
from pathlib import Path

DATA_DIR = Path(__file__).parent.parent.parent / 'data'


class SkinManager:
    """皮肤表管理：data/skins.json，key 为舰娘 id"""

    def __init__(self, skin_file: Path | None = None):
        path = skin_file or (DATA_DIR / 'skins.json')
        with open(path, 'r', encoding='utf-8') as f:
            self.skins_db: dict = json.load(f)

    def get_skins(self, sg_id: str) -> list[dict]:
        """某舰娘的全部皮肤"""
        return list(self.skins_db.get(sg_id, []))

    def get_skin(self, sg_id: str, skin_id: str) -> dict | None:
        """按舰娘+皮肤 id 查询"""
        for s in self.get_skins(sg_id):
            if s['id'] == skin_id:
                return s
        return None
```

```python
def can_change_skin(world: World, npc):
    '''换装判定：拥有该舰娘的任意皮肤'''
    if not global_can(world.player, npc):
        return False
    return len(world.player.skins.get(npc.id, [])) > 0


@register_cmd('change_skin', '换装', '日常', can_change_skin)
def change_skin(world: World, option):
    '''为舰娘更换已拥有的皮肤'''
    ctx = CommandContext(world)
    packed = _unpack(option)
    if not packed:
        return []
    npc_id, payload = packed
    if not payload:
        return []
    npc = world.npc_manager.get_npc_by_id(npc_id)
    skin_id = payload['skin_id']
    if skin_id not in world.player.skins.get(npc_id, []):
        return ['还没有这件皮肤']

    npc.skin = skin_id
    skin = world.skin_manager.get_skin(npc_id, skin_id)
    name = skin['name'] if skin else skin_id
    ctx.say(f'{npc.name}换上了「{name}」！')

    line = npc.get_line('change_skin')
    if line:
        ctx.say(line.replace('{name}', npc.name))
    return ctx.result()
```
