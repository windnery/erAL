# erAL

era-碧蓝航线（开发中）

---

## 介绍
- 《碧蓝航线》（Azur Lane）同人 ERA 风格文字角色扮演 / 互动养成游戏。
- 基于 Python 与 Web 前端 UI (pywebview) 架构独立开发。
- 当前游戏处于 α 测试阶段（Alpha / 原型开发），部分功能与内容仍在持续搭建与填充。
- 个人独立开发，抽空更新，有生之年系列。

---

## 普通玩家指南
1. 在仓库右侧 Releases 下载最新打包好的 Windows 压缩包（如 `erAL_v0.1.0-alpha_win64.zip`）；
2. 解压到本地文件夹，双击运行 `erAL.exe` 即可开始游戏；
3. 绿色免安装，解压即玩，游戏存档会自动保存在游戏根目录下的 `sav/` 文件夹中。

---

## BUG 反馈
当遇到游戏闪退或异常时：
1. 检查游戏根目录下的 `logs/crash.log` 文件；
2. 在本仓库的 Issues 页面提交反馈；
3. 为方便快速定位排查，请在反馈时附带：
   - 游戏版本号（如 `v0.1.0-alpha`）
   - 报错前大致在执行什么操作
   - `logs/crash.log` 中的错误日志内容
   - 若属于特定状态异常，可附带 `sav/` 目录下的对应存档文件

## 开发者指南（源码运行与打包）

### 环境要求
- Python 3.10+ (推荐 3.11 / 3.12)
- Windows 10 / 11

### 1. 安装依赖
```bash
git clone https://github.com/windnery/erAL.git
cd erAL
pip install pywebview pytest pyinstaller
```

### 2. 源码启动
```bash
python main.py
```

### 3. 运行测试
```bash
python -m pytest
```

### 4. 本地打包 Exe
```powershell
pyinstaller erAL.spec
```
构建产物将输出在 `dist/erAL/` 目录下。

---

## 推荐配置
- 操作系统：Windows 10 / Windows 11
- 显示器分辨率：推荐在 1080P（1920×1080）及以上分辨率显示器上运行以获得最佳排版效果
- 内存占用：约 200MB ~ 500MB
